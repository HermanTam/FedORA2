LEGEND
--------------------------------------------------------------------------------
Personalization (P) Clients: P-clients on current local test (final slot).
Generalization (G) Clients: G-clients on previous (old) local test (final slot; if available).
Overall (All Clients): All clients on current local test (final slot).
GLOBAL TEST (Global P/G): P/G-clients on the fixed global test set (baseline).
Objective-aware GLOBAL: Mix by objective, P→local current; G→fixed global test set (final slot).
P_on_local / G_on_local: P/G-clients on current local test.
P_on_global / G_on_global: P/G-clients on the fixed global test set.
Overall Global (All Clients): All clients on the fixed global test set.
TASKS@FINAL (Rotation): Mean accuracy at final slot on rotation-stratified test sets (0°, 120°, 240°).
ALL PAST CONCEPTS @ FINAL: Mean accuracy across all stored past test iterators.
TASKS@FINAL (12-task test clients): Per-task train/test accuracy on 12 held-out tasks (4 concepts × 3 rotations) using global models.
  'All tasks' uses all 12; 'P/G tasks' restrict to test clients whose objective is P or G.
Objective-aware OLD (P:local, G:old) is intentionally omitted here.
